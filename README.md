# Gmail-Automation
An automated email classification and routing workflow built with Make.com and Google Gemini AI. It watches incoming Gmail messages, categorizes them into Billing, Tech, or General streams, processes each via specialized AI prompt modules, and dispatches automated replies—streamlining customer communication and inbox triage.
